Reading guide.

页面中应观察什么

DFlash

并行 masked block、逐位置 proposal 分布及其在 target verification 中的连续接受情况。

DSpark

Markov 顺序修正、confidence 信号，以及半自回归 proposal 如何缓解 suffix decay。

EAGLE-3

candidate tree 的扩展与验证；accepted path 和 tree budget 如何共同影响每轮产出。
